# 한살림 임산부꾸러미 (HANSALIM MOM KIT)

한살림 임산부꾸러미의 실제 물품·사진·이용안내를, 요즘 많이 쓰는 '일체형 웹페이지' 구성으로 다시 만든 친환경 꾸러미 쇼핑몰 포트폴리오입니다.
PC에서는 가운데 모바일 화면과 왼쪽 검색 패널을, 모바일에서는 화면 전체를 쓰는 하나의 페이지로 탐색 → 담기 → 주문까지 쇼핑몰 전체 흐름을 구현했습니다.

> 포트폴리오용 사이트입니다. 실제 한살림과 협업한 결과물이 아니며, 로그인·주문은 서버 없이 브라우저에만 저장되는 시연 기능입니다. 타임딜 할인과 후기는 디자인 예시입니다.

## 프로젝트 개요

- **기간**: 32시간
- **역할**: 기획, UI 디자인, 개발 (1인)
- **도구**: Figma, VS Code, Claude
- **기술**: React 19, Vite, React Router, localStorage

## 기획 의도

- **일체형 웹페이지란**: PC에서도 모바일 크기(최대 480px) 화면을 가운데 두고, 남는 양옆 공간에 검색·배너·바로가기를 두는 구성
- **일체형으로 만든 이유**
  - 한 화면으로 PC·모바일 대응 (화면을 두 벌 만들 필요 없음)
  - 어디서나 같은 사용 경험 (휴대폰으로 장 보던 사용자가 PC에서도 헤매지 않음)
  - 남는 공간 활용 (PC 양옆에 검색창·인기 태그·배너 고정)
  - 관리와 수정이 쉬움 (한 곳만 고치면 됨)
- **타깃**: 임신 중이거나 출산한 지 얼마 안 된 엄마. 휴대폰으로 틈틈이 장을 보고, 지원 사업의 포인트·주문 규칙이 낯선 사용자
- **콘셉트**: 건강한 · 친환경 · 쉬운 — "엄마와 아이의 건강을 응원하는, 쉬운 친환경 장보기"
- **벤치마킹**: 일체형 쇼핑몰 시안의 섹션 순서와 디자인을 살리고, 내용·사진은 실제 한살림 임산부꾸러미로 채움

## 주요 기능

- **일체형 레이아웃**: PC에서는 가운데 모바일 화면 + 왼쪽 검색 패널, 모바일에서는 전체 화면. 헤더·하단 고정 메뉴·햄버거 메뉴·검색창에서 모든 페이지로 이동
- **가입부터 주문까지**
  1. 아이디 만들기 → 꾸러미 포인트 240,000원 즉시 지급
  2. 인기물품·햇물품·요리 재료 담기
  3. 장바구니에서 실제 이용안내 규칙 자동 확인
     - 1회 주문 4만 원 이상 10만 원 이하
     - 농산물 비중 50% 이상 (비중 막대로 표시)
  4. 주문 시 80%는 포인트(1회 최대 8만 원), 20%만 본인 결제
  5. 마이페이지에서 남은 포인트·주문내역 확인
- **상태 저장**: 장바구니, 관심상품, 최근 본 상품, 가입·로그인 정보를 localStorage에 저장
- **물품 데이터**: 실제 물품 37개, 카테고리 9종 (`src/data/product.json`)
- **새로고침 대응**: `vercel.json`으로 모든 주소를 `index.html`로 연결해 서브페이지 404 방지

## 폴더 구조

```
hansalim-kit/
├─ index.html
├─ vercel.json          서브페이지 새로고침 404 방지
├─ public/images/       실제 사이트 사진
├─ docs/                기획서 PDF
├─ figma-plan-plugin/   기획서 슬라이드 생성용 Figma 플러그인
└─ src/
   ├─ components/       홈 섹션, 헤더, 햄버거 메뉴, 팝업
   ├─ pages/            서브페이지 11개
   ├─ data/product.json 물품·카테고리 데이터
   └─ store.jsx         장바구니·관심상품·로그인·주문 규칙
```

## 실행 방법

```
npm install
npm run dev
```

`index.html`을 Live Server로 직접 열면 흰 화면이 나옵니다. 반드시 Vite로 실행해 주세요.
